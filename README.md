# JACE BOOM BOX

A premium skeuomorphic soundboard. Every `.mp4` file in `/audio` automatically becomes an audio pad (audio only, video is ignored).

Built with **Python + HTML + CSS + JavaScript** only. No database or cloud services. Lists, theme and volume are saved in the browser's `localStorage`.

## Features

- Builds the audio library automatically from `/audio/*.mp4`, using the file names as labels
- Plays only one sound at a time. Starting a new sound stops the current one right away
- Search by audio name or filename (press `/` to focus it)
- Custom lists (Birthday, Townhall, Awards Night, …): create, rename, delete, add to and remove from
- Quick controls: Stop (`Esc`), Mute (`M`), volume fader, live VU meter
- Now Playing panel showing the file name, status and progress (you can seek)
- Light and Dark mode, with 6 accent colors: Blue, Violet, Green, Orange, Pink, Grey
- Responsive layout for desktop, tablet and mobile

## Project structure

```
├── index.html        # App markup
├── css/styles.css    # Skeuomorphic theme (light/dark + accents)
├── js/app.js         # Player, library, lists, search, storage
├── audio/            # Put your MP4 files here
│   └── manifest.json # Auto-generated by build.py
├── build.py          # Scans /audio and writes audio/manifest.json
├── server.py         # Local dev server (re-scans /audio live)
└── vercel.json       # Vercel config (runs build.py on deploy)
```

## Run locally

```bash
python server.py          # http://localhost:8000
python server.py 9000     # custom port
```

`server.py` re-scans `/audio` each time the manifest is requested. The open page polls every 10 seconds, so when you drop new MP4 files into `/audio` they show up without a reload.

> Opening `index.html` directly (`file://`) will not work, because browsers block folder scanning. Use `server.py`.

## Adding sounds

1. Copy `.mp4` files into `/audio`.
2. Locally, nothing else is needed. For deployment, commit and push; Vercel runs `build.py` and regenerates the manifest.

Button labels come from the file names. For example, `drum roll.mp4` becomes **Drum Roll**.

## Deploy to GitHub + Vercel (free)

```bash
git init
git add .
git commit -m "JACE BOOM BOX"
git branch -M main
git remote add origin https://github.com/<you>/jace-boom-box.git
git push -u origin main
```

Then on vercel.com choose **Add New → Project**, import the repo and click **Deploy**. `vercel.json` already sets the build command (`python3 build.py`). No other settings are needed.
